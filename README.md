# Loop Arror

An experimental browser-based audio manipulation tool built with JavaScript and the Web Audio API.

Loop Arror is designed for playful experimentation with your own audio loops.  
Instead of focusing on perfectly prepared loops, it can also turn imperfect cuts,
unexpected loop points and small timing irregularities into new layers, textures
and sounds.

## Features

- Four independent audio slots
- Load and combine your own audio loops
- Individual loop point manipulation
- Pitch and playback controls
- Audio effects for further sound manipulation
- Real-time browser-based playback
- No installation required

Loop Arror does not include any audio material. Bring your own loops and record
the results externally if you want to keep them.

## Built with

- HTML
- CSS
- JavaScript
- Web Audio API
